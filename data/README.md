Temperature dashboard project

############################

This file provide links to the raw temperature dataset used in this study. This file is too large to include in this repository, 
but below you will find details where to download the data. 

Raw netcdf file of gridded surface temperatures used in this study were downloaded from:
https://berkeleyearth.org/data/

Specifically, we use the Global Monthly Land + Ocean average Temperature with air temperature at sea ice on a 1 degree x 1 degree Latitude Longitude grid. Downloaded on April 8, 2025.
